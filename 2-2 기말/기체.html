시험 직전 핵심 20

  1. 기체 주요 구조: 동체 · 날개 · 꼬리날개 · 착륙장치 · 기관 마운트/나셀 (+조종계통)
  2. 기체에 작용하는 하중 5가지: 인장 · 압축 · 전단 · 굽힘 · 비틀림
  3. 날개 1차 구조 = 날개보(spar) · 리브(rib) · 외피(skin) / 동체 1차 구조 = 벌크헤드 · 세로대 · 프레임 · 스트링거
  4. 2차 구조 예: 날개보 2개인 날개의 앞전 부분 (손상 시 성능 저하, 바로 사고 X). 객실 선반·문고리·칸막이는 구조 부재 아님
  5. 모노코크 = 외피가 하중 전부 (두꺼운 외피 → 무거움 → 미사일에 사용)
  6. 세미모노코크 = 외피 전단 응력, 골격 인장·압축·굽힘 → 현대 동체에 가장 많이 사용
  7. 페일세이프 4종: 다경로(Redundant) · 이중(Double) · 대치(Back-up) · 하중경감(Load dropping)
  8. 구조 부재는 최대 하중에서 3초 이상 견디도록 설계
  9. 샌드위치 심재: 벌집형 · 거품형 · 파형 / 단점: 국부 하중에 약함, 손상 파악 곤란, 고온에 약함
  10. 워렌 트러스 = 수직 구조재 없음 → 공간 많고 유선형 / 프랫 = 세로대 + 수직 웨브 + 대각선 보강선
  11. 벌크헤드 위치: 동체 앞·뒤, 날개·착륙장치 부착부, 비틀림 저항 + 집중하중을 외피에 분산
  12. 여압실 단면: 이중 거품형(double bubble) — 동체 높이 증가 없이 넓은 공간
  13. 윈드실드 강도: 외측판 여압의 7~10배, 내측판 3~4배, 1.8 kg 새 충돌(순항속도)
  14. I형 날개보 굽힘 시: 상면 플랜지 압축, 하면 플랜지 인장, 웨브 전단
  15. 압축 리브 = 가장 튼튼한 리브 (나셀·착륙장치·플랩·보조익 fitting 장착부, 날개보 간격 유지)
  16. 파울러 플랩 = 트랙 따라 후퇴 → 시위·면적 증가, 양력계수 가장 크게 증가
  17. 도움날개: 뒷전 바깥쪽(플랩은 안쪽), 차등 조종(올림각 > 내림각), 고속 시 inboard만 작동
  18. 식수 탱크 가압: 블리드 에어/APU 공기압으로 펌프 없이 공급 (B737 약 25 psi)
  19. 진공 변기: 16,000 ft 이하 → Vacuum Blower, 이상 → 기내·외 자연 차압
  20. Flush 차단(Inhibit): Waste Tank Full · 지상 서비스 중 · 물 공급 부족

2. 1차 구조 vs 2차 구조

1차 구조2차 구조
정의기체의 중요 하중 담당, 파손 시 심각한 결과비교적 작은 하중, 파손 시 적절한 조치로 사고 방지 가능
예날개: spar, rib, skin
동체: bulkhead, longeron, frame, stringer		날개보 2개인 날개의 앞전 부분 → 공력 성능 저하는 있으나 곧바로 사고로 직결 X
객실 선반, 문고리, 칸막이 등은 구조 부재가 아니다.

3. 트러스 구조 (Truss)

  • 인장·압축의 2력 부재로 구성, 목재 또는 강관으로 트러스 형성, 천/얇은 합판/금속판 외피
  • 트러스(뼈대)가 모든 하중 담당 / 외피는 형태 유지 + 공기력을 트러스에 전달만
  • 경비행기·목재 비행기 사용. 종류: Pratt truss, Warren truss
  • 장점: 설계 간단, 제작 용이, 저렴 / 단점: 내부 공간 마련 곤란, 유선형 제작 곤란

4. 응력 외피 구조 (Stressed Skin) — 모노코크 vs 세미모노코크

모노코크 (Monocoque)세미모노코크 (Semi-monocoque)
하중 담당외피가 모든 하중외피 + 골격 공동 담당
외피 = 전단 응력 / 골격 = 인장·압축·굽힘 등 나머지
특징내부 공간 크고 유선형 가능. 작은 손상도 전체에 영향 → 두꺼운 외피 → 무게 증가로 기체 구조로 부적합 (미사일)현대 항공기 동체에 가장 많이 사용, 최소 무게로 최대 강도, 결합은 주로 리벳(때로 볼트)

5. 페일 세이프 구조 (Fail-safe) — 4종 꼭 구분!

한 부분이 파손돼도 발견·수리할 때까지 나머지 구조가 하중을 담당해 안전 비행이 가능한 구조

종류설명 (키워드)
다경로 하중
Redundant		하중 경로를 여러 개 → 1개 파괴돼도 다른 경로로 전달
이중 구조
Double		2개의 작은 부재를 결합해 하나의 부재 → 일부 손상이 전체 파손으로 가지 않음
대치 구조
Back-up		파손 대비 예비 부재 삽입 (예비 부재가 다른 기능을 겸하기도)
하중 경감
Load dropping		큰 부재 위에 작은 부재를 겹쳐 만든 구조 → 파괴 시작 시 주변 부재로 하중 전달, 완전 파단 방지
구조 부재는 설계 최대 하중으로부터 3초 이상 견딜 수 있어야 함.

6. 샌드위치 구조

  • 2장의 외판 사이에 가벼운 심재(core)를 넣어 접착제로 고착
  • 심재: 벌집형(honeycomb), 거품형(foam), 파형(wave)
  • 사용처: 보강재 사용이 어려운 곳 — 날개·꼬리날개·조종면의 끝 부분, 동체 마루 바닥
  • 장점: 무게 대비 강도↑, 음진동·피로·굽힘에 강함, 보온·방습 우수, 진동 감쇠↑, 국부 버클링에 강함
  • 단점: 극히 일부분 하중(국부 하중)에 약함, 손상 파악 곤란, 고온에 약함 (하니컴: 화재·수분에 약함)

7. 설계 개념 비교

안전수명 (Safe-life)페일세이프 (Fail-safe)손상허용 (Damage Tolerance)

2장 동체기체(2) PDF

1. 동체 구조 형식

  • 트러스형 동체 — Pratt / Warren
  • 응력 외피형 동체 — 세미모노코크 / 모노코크

2. 트러스 구조형 동체

  • 삼각형 집합체, 뼈대가 하중, 표피는 기하학적 형태 유지
  • 재료: 저탄소강 강관, 니켈-크롬-몰리브덴강
  • Pratt: 세로대 + 수직 웨브, 대각선에 보강선(wire)으로 강도 유지
  • Warren: 수직 구조재가 없음 → Pratt보다 여유 공간 많고 유선형 가능
저탄소강중간 탄소강고탄소강
C 0.25% 이하C 0.25 ~ 0.60%C 0.6 ~ 1.7%

3. 응력 외피형 동체

  • 모노코크: 벌크헤드 + 정형재(Former)에 두꺼운 외피 → 외피가 응력 담당 → 동체엔 부적합, 미사일에 사용
  • 세미모노코크: 프레임·벌크헤드가 동체 형태 구성 + 길이 방향 세로대·스트링거 보강 + 외피
세로(길이) 방향 골격
  • 세로대 (Longeron): 세로 방향 주 구조재, 길이 방향 연속 부착
  • 스트링거 (Stringer, 세로지): 세로 방향 보강재, Ring과 함께 외피를 작은 사각형으로 분할 → 외피 주름(버클링) 방지
  • 단면: I, Z, T, N, H형 (굽힘 모멘트에 의한 인장·압축 대응)
수직(가로) 방향 골격
  • 벌크헤드 (Bulkhead, 가로격판): 수직 방향 주 부재, 두껍고 튼튼. 비틀림 변형 저항, 집중하중을 외피에 골고루 전달. 위치: 동체 앞·뒤, 날개·착륙장치 부착부 (여압 격벽 포함)
  • 링 (Ring): 가로 방향 보강재, Stringer와 15~50 cm 간격, 외형 유지 + 주름 방지
  • 정형재 (Former): 합금판 성형, 동체 형태 구축
외피 (Skin): 얇은 알루미늄 합금판, 골격에 리벳 고정. 전단 응력 + 비틀림 응력 담당 (때로 스트링거와 함께 압축·인장도)

4. 프레임·스트링거를 외피에 접합하는 방법

방법특징
㉠ 스트링거·프레임 모두 외피에 직접 접합응력 분포 균등 → 여압식 동체에 많이 적용
㉡ 프레임이 스트링거 안쪽에 접합 (외피와 직접 X)스트링거-외피 접합부에 응력 집중, 프레임이 튀어나와 탑재 용적 감소

5. 동체의 구분

  • 전방 동체: 공기저항 최소 형상, 조종실 시계 확보
  • 중간 동체: 승객·화물 공간, 날개 및 주 착륙장치 부착부
  • 후방 동체: 승객·화물 탑재 / 후방 몸체(After body): 꼬리날개 부착부
  • 프레임은 수평 마루보(Floor beam)에 부착 → 여압 하중 견딤, 길이 방향 세로보(Longitudinal beam)로 하중 분산

6. 여압실

  • 공기원: 피스톤 엔진 → 과급기 압축공기 / 제트기 → 압축기 배출(블리드) 공기
  • 고공일수록 차압↑ → 스트링거 간격 좁힘, 고강도 스트링거, 티타늄 합금
  • 기밀: 외피판·리벳 접합부에 밀폐제(Sealant)
  • 케이블·조종 로드가 외벽 통과 시: 스프링과 고무 실, 그리스와 와셔 실, 고무 콘
  • 단면: 이중 거품형(Double bubble) — 동체 높이 증가 없이 넓은 공간

7. 조종실 창문 · 윈드실드 · 객실 창문 · 출입문

항목핵심
윈드실드 구조내·외측 유리 사이 비닐층 코어 샌드위치. 외측판 안쪽 금속 피막(conductive coating) → 보온·방빙·제빙. 비닐층은 전기로 가열돼 플라스틱 상태 → 충격 흡수
윈드실드 강도외측판: 여압의 7~10배 / 내측판: 3~4배 / 순항 중 1.8 kg 새 충돌에도 파괴 X
객실 창문두 장의 연성 유리, 사이로 여압 공기 통과, 바깥쪽 판만으로 최대 여압 감당, 바깥판은 외피 안쪽에 볼트 부착, 주위는 seal. 원형/둥근 모서리 = 응력 집중 억제
출입문동체 외벽과 동일 부재 이상 강도.
① 플러그형(plug type): 동체 안쪽으로 열림 → 기밀 용이
② 밖으로 여는 문: 팽창식 실(seal) 사용

3장 날개기체(3) PDF

1. 날개 일반

  • 역할: 양력 발생, 연료탱크(integral), 기관·착륙장치·조종장치·고양력장치 부착
  • 주날개 → 롤링 / 수평꼬리날개 → 피칭 / 수직꼬리날개 → 요잉
  • 비행 중 하중: 공기력·중력·관성력, 양력에 의한 굽힘·비틀림
  • 휨(굽힘) 응력: 날개 하중 + 풍압 항력 / 비틀림 응력: 길이 방향 익형들의 공력 중심 위치가 달라서 발생
  • 설계 고려: 하중·변형 문제, 장착 장치로 인한 구조적 불연속 → 집중하중

2. 날개 구조 형식

트러스형 날개세미모노코크형 날개
소형 경항공기. 날개보 + 리브 + 버팀선(bracing wire)이 하중 담당. 외피(금속판·합판·우포)는 형태만. 전단·휨·비틀림 → Spar·Rib 담당날개보(2~3개: 앞·중간·뒷) + 리브 + 스트링거 + 외피. 날개보와 외피가 상자형(box) 구조. 날개보 → 축력·굽힘 / 외피 → 비틀림 + 축력 증가분을 전단 흐름으로

3. 날개 구조 부재

부재역할 / 종류
날개보 Spar길이 방향 주 부재, 굽힘력 담당 (주요 하중: 굽힘·비틀림). 종류: 트러스형(용접) / I형(위·아래 플랜지 + 얇은 웨브).
굽힘 시 상면 플랜지 압축 · 하면 플랜지 인장 · 웨브 전단. 날개-동체 연결부, 착륙장치·기관도 날개보에 장착
리브 Rib익형(단면) 유지, 외피 하중을 날개보에 전달, 앞·뒤 Spar 간격 유지
· 정형 리브(Former): 날개 형태 · 앞전 리브(Nose): 전연 모양
· 압축 리브(Compression): 나셀·착륙장치·플랩·보조익 fitting 장착, 전연 압축하중을 날개보에 전달, 간격 유지 → 가장 튼튼
· 구조 형식: 트러스 리브 / 스탬프 리브 · 중량 경감 구멍(lightening hole)
스트링거날개 굽힘 강도 증대, 비틀림에 의한 좌굴 방지, 리브에 리벳 고정. 단면 L형·M형·모자형. 일체형 날개 = 스트링거와 외피를 일체 제작(최소 무게·고강도)
외피 Skin앞 날개보~뒷 날개보 사이 외피 = 응력 외피 (높은 강도). 앞전·뒷전은 공력 형태 유지

4. 날개 장착 방식

지주식 (Braced)외팔보식 (Cantilever)
구조날개 하부~동체를 날개 지주(Strut)로 연결지주 없이 동체 장착부에 고정 → 응력이 장착부에 집중 → 벌크헤드·프레임 보강
장점장착부에 휨모멘트·전단력 안 걸림, 가볍고 장착 용이항력 적음 → 고속기
단점지주 공기저항 큼 → 소형 경항공기만. 비행 중 지주는 인장하중강도 확보 위해 무거움. 날개보 3개 사용하기도. 장착 핀: 앞·뒤 날개보 뿌리 상하 각 2개, 서로 다른 방향

5. 연료 탱크

종류특징
인티그럴 (integral)앞·뒤 날개보 + 외피를 밀폐해 날개 내부 자체를 탱크로. 대형기, 가벼움
블래더 (bladder)합성고무 탱크를 별도 제작해 날개보 사이 장착.
Self-sealing: 파손 시 자체 밀폐, 구식 군용기 / Non-self-sealing: 밀폐 효과 X, 연료 적재량 큼
셀형 (cell)금속 탱크를 날개보 사이에 내장

6. 앞전 고양력 장치

  • 슬랫(Slat): 앞에서 upwash 유도, 고에너지 흐름을 윗면으로 → 박리 지연·실속 방지. 아음속 여객기, 최대양력계수 50~90% 증가. (슬롯 = 공기가 흐르는 길)
  • 고정 슬롯: 하면 기류를 상면으로 → 박리 지연
  • 드룹 노즈(Droop nose): 구조 간단, 슬랫보다 저효율, 초음속 전투기 (저속에서 앞전 내림)
  • 크루거 플랩(Krueger): 얇은 날개에 부착 용이, 캠버·앞전 반지름 증대
  • 로컬 캠버: 앞전이 앞으로 굽혀 나와 시위·익면적 증대

7. 뒷전 고양력 장치 (플랩) — 이착륙 거리 단축

플랩핵심 키워드
플레인 (Plain)힌지로 캠버 변화, 효율 낮음, 전투기. 10~15° 초과 시 너클 뒤 박리
스플릿 (Split)날개 하단 평판, 구조 간단·가벼움, 와류(항력) 커서 잘 안 씀
슬롯 (Slotted)하면 기류를 상면으로 → 박리 방지, 40°까지
파울러 (Fowler)트랙 따라 이동 → 시위·익면적 증가, 양력계수 가장 크게 증가
이중 슬롯내림각↑, 박리 현저히 지연 → 여객기
삼중 슬롯앞·중간·뒤 플랩, 대형 여객기
잽 (Zap)스플릿 플랩 개선(뒷전 와류 감소), 구조 강도 문제
블로우 플랩 / 블로우 제트제트 배기가스 이용해 양력 증대

8. 도움날개 · 스포일러

도움날개 (Aileron)
  • 뒷전 바깥쪽 (플랩은 안쪽)
  • 세로축 중심 옆놀이(Rolling) 발생·제어
  • 좌우 반대 작동, 올림각 > 내림각 = 차등 조종(Differential Control)
  • 대형기 좌우 2개씩: 저속 → 모두 작동, 고속 → 안쪽(inboard)만
  • 대형기는 벌집 샌드위치 일부 사용
스포일러 (Spoiler)
  • 날개 뒤편 상단, 판막처럼 들려 항력↑
  • 양력 감소·항력 증대 → 비행 중 속도 감소
  • 롤 조종 시 도움날개 보조 (2차 조종면)
  • 공중 스포일러 = 비행 중 속도 제동 / 지상 스포일러 = 착륙 시 전체 작동, 제동 효과

9. 방빙 · 제빙

방빙 (Anti-icing) — 얼지 않게제빙 (De-icing) — 언 것을 제거
① 전열식: 전열선으로 앞전 가열
② 가열 공기식: 압축기 배출 뜨거운 공기		① 알코올 분출식: 앞전 구멍으로 알코올 분출, 빙점 낮춤 (이소프로필 알코올, -40℃)
② 제빙 부츠: 앞전 공기주머니에 압축공기를 맥동적으로 공급 → 팽창·수축으로 얼음 깸

Water & Waste System (ATA Chapter 38)Water & Waste PDF

ATA 38의 3개 하위 시스템
  • 식수(Potable Water) 시스템: 식수·세척용 물 공급 (갤리, 세면대, 변기 플러싱)
  • 폐수(Waste water, Gray water) 시스템: 세면대·갤리 사용 물 배출 → 드레인 마스트로 기외 배출
  • 화장실(Toilet, Black water) 시스템: 오물을 진공으로 흡입 → 탱크에 저장, 지상에서 배출

1. 식수(Potable Water) 시스템

  • 저장: 기체 하부/화물칸 인근 탱크
  • 가압 방식: 엔진/APU 블리드 에어로 탱크 가압 → 별도 펌프 없이 물을 밀어냄
  • 지상이나 블리드 부족 시 전동 컴프레서 작동. 압력 스위치: 하한(Cut-on) 이하 → 켬, 상한(Cut-off) → 끔
  • 가압 공기 계통 부품: 압력 조절기(Regulator) — 탱크 파손 방지(10 µ 필터) / 체크 밸브 — 물·습기가 공기 라인으로 역류 방지 / 릴리프 밸브 — 과압 시 압력 배출
  • 컴프레서 인터록 스위치: 과압·저압 보호, 물탱크 빈 상태 공회전 방지, 문제 해결 전까지 잠금 유지
  • 잔량: 센서 → 승무원 패널(FAP)에 Empty, 1/4, 1/2, 3/4, Full
  • 동파 방지: 영하 장기 주기 시 탱크·배관 물 완전 배수
기종식수 탱크
B737 오리지널(-100/200/300)30 US gal (약 114 L)
B737 클래식 후기(-400/500)40 US gal (약 151 L)
B737 NG / MAX60 US gal (약 227 L), 후방 화물칸 뒤, 단열재(Thermal blanket), 약 25 psi 가압
A38075 gal(283 L) × 6개 = 약 1,700 L, 후방 화물칸 전방(좌3·우3), 35~41 psi, 옵션 시 center wingbox에 2개 추가(총 8개)
일반적인 물탱크 가압은 슬라이드에 35~50 psi로 나와 있어요. 기종별 수치(737 약 25 psi, A380 35~41 psi)와 섞어서 물어볼 수 있으니 구분해 두세요.

2. Water Service Panel (식수 서비스 패널)

  • 위치: 동체 하부/후방 측면. 지상 급수차와 연결해 급수(Fill)·배수(Drain)
  • Fill/Drain Control Handle: FILL – NORMAL – DRAIN 모드 선택
  • Quantity Indicator(수량계), 상태 표시등(Tank Full / Overflow / Drain)
  • Overflow & Drain Port: 넘친 물을 외부로 배출 / Ground Pressure Port: 지상 공기압 연결
  • Door Microswitch: 패널 문 개폐와 시스템 연동(안전)
  • Tank Drain Valve: 탱크 최저점, 평소 스프링으로 밀폐, 공구로 개방, 작업 후 누수 확인
  • Preselection Unit: 급수량을 미리 설정 → 필요한 양만 실어 중량·연료 절감 (A330: Bulk cargo door 근처)

3. 폐수 배출 관련 부품

부품역할
드레인 마스트 (Drain Mast)세면대·갤리 폐수(gray water)를 비행 중 동체 외부로 배출. 동체 하부 돌출. 히터로 결빙 방지. (B787은 마스트 없이 탱크에 모으기도)
GWDUGalley Waste Disposal Unit — 갤리 남은 음료·액체·찌꺼기를 하부 오물 탱크로 배출

Vacuum Generator진공 압력차로 갤리/화장실 폐기물 흡입 → 배관 막힘 방지

4. 진공 변기 (Vacuum Toilet) 작동

고도진공 형성 방법
지상·저고도 (약 16,000 ft 이하)기압차 부족 → Vacuum Blower(전동식)가 탱크를 강제 음압
고고도 (16,000 ft 이상)객실(약 8,000 ft 수준)과 외기의 자연 차압 이용, 블로워 정지, Vent valve 열림
Flush Cycle (약 4~6초) — 제어: FCU / VSC(Vacuum System Controller)
① 신호 감지 (고도·탱크 Full 확인) → ② 린스 (약 0.2~0.4 L 분사, Spray ring) → ③ Flush Valve 오픈 → ④ 이송·분리 (Separator: 공기는 배출, 오물은 탱크) → ⑤ 복귀 (밸브 닫힘·밀봉)
Flush Inhibit(차단) 조건 3가지: ① Waste Tank 100% Full ② 지상 서비스 중(Waste Service Panel 열고 배출 중) ③ 물 공급 부족(No Water)
  • 변기 내부 테플론(비고착) 코팅 → 소량의 물로 세척 (1회 0.5 L 미만), 흡입 약 320 km/h, 블루 주스(Skykem) 소독·탈취
  • 변기 재질: 도기 대신 스테인리스·복합재 → 경량화
  • Toilet Shroud: 변기 하부 배관·밸브를 가리는 밀폐형 보호 커버. Seal/실란트 손상 → 오물이 바닥 구조물로 → 부식(Corrosion)

5. Waste Tank (오물 탱크)

  • 재질: 티타늄 또는 복합재, 내벽 테플론 코팅
  • Inlet Pot: 오물 유입구 (스플래시 플레이트) / Separator: 기·액 분리 / Rinse(Flush) Ring: 지상에서 탱크 내벽 세척 / Quantity Sensors
  • 센서: Continuous level sensor(0~100% 연속) + Point level sensor(100% 감지 전용) → Point 센서 신호가 우선권
  • 정비: 요석(Urine scale) → 센서 오지시(False Full)·밸브 누설 → 정기 화학 세척(12,000 FH 주기) / Anti-odor(카본) 필터 정기 교체
  • Full 시 지시: CAP에 'WASTE TANK FULL', LO/HI 차임 2회, Flush 스위치 작동 불가, 'Lavatory Inoperative' 점등, EICAS/CMC 기록

6. Waste Service Panel

  • 위치: 동체 후방 하부, 지상 Lavatory Service Truck과 연결
  • Waste Drain Valve & Coupler (4인치) + 밸브 핸들/케이블
  • Flush Ring Line Connection: 배출 후 세척수·세정제 주입
