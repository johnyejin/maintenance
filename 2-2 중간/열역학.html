열역학과 계

열역학이란

정의

열역학(熱力學)은 의미 그대로 열(熱)과 일(力: 힘)과의 관계를 다루는 학문.

물질의 구조에 대해서 고려할 필요는 없으며 물질을 연속체(continuum)로서 취급한다. 분자와 분자 사이에 넓은 간격이 있어도 무시하고, 꽉 찬 하나의 덩어리로 본다는 뜻.

상태량 property

열과 일의 변화 관계의 매개체는 상태량의 변화로 직접 나타난다.

열역학적 계 thermodynamic system

피스톤을 압축(팽창)하면 점선 안 기체의 온도, 압력, 밀도가 증가(감소)한다. 이렇게 증감의 관심 대상이 되는 공간이나 물질을 계(system)라 한다. 점선 부분은 경계(boundary), 계 외부의 물질은 주위(surroundings).

② 개방계: 질량, 중량 출입이 있다. 계와 주위 사이에 물질 교환이 있다.

작동유체 working substance, 작동물질

계 내부의 기체는 외부의 일이나 열을 받아 에너지를 축적·저장하며 쉽게 상변화하는 물질 = 작동유체(동작물질).

즉, 피스톤을 압축하면(일을 가하면) 계의 온도가 증가하고, 증가된 온도가 주위와의 온도차에 의해 열이 방출된다.

예: 보일러의 증기, 내연기관의 연료와 공기, 증기터빈의 증기, 냉동기의 냉매

TIP

인체 내 혈액, 자동차 연료, 냉장고 냉매처럼 목적 성취를 위해 꼭 필요한 물질. 작동유체의 상이 변한다(액체 → 기체 → 액체)는 말은 기본상태량 PVT가 변한다는 뜻.

계의 상태와 성질, 상태변화

성질 = 상태량

열역학에선 ①→②로 갈 때 경로에 상관없이 ①이 ②가 됐다만 따짐

한 상태에서 물질의 성질(=상태량)은 단 하나의 값을 가지며, 어떤 경로로 그 상태에 도달했는지와 관계없이 항상 같다.

정의

성질은 경로에 관계없이 계의 상태에만 관계되는 양으로 정의되므로 상태함수(state function) 또는 점함수(point function)라고 한다.

강도성과 종량성

강도성 intensive

질량에 무관한 성질

온도, 압력

★ A4

종량성 extensive

질량에 비례하는 성질 (질량 크기에 따라 변화)

체적, 에너지 (위치에너지, 운동에너지)

질량을 반으로 줄여도 강도성 값(온도, 압력)은 변하지 않는다.

상태변화와 과정

정의

어떤 물질 단위중량을 1 °C만큼 높이는 데 필요한 열량. 단위 kcal/kgf·°C (공학), kJ/kg·K (SI)

어떤 물체에 열량 δQ를 가했을 때 물체의 온도가 dt만큼 상승했다면, 온도 상승값 dt는 가해진 열량 δQ에 비례하고 물체의 중량 G에 반비례한다.

차이는 분모에 온도(°C)가 있느냐.

  • 비열: "1 kg을 1 °C 올리는 열량" → 질량당 + 온도당
  • 잠열: 상변화 중엔 온도가 안 변함 (물은 끓는 동안 계속 100 °C) → 나눌 온도가 없음
  • 감열: 비열 × 온도변화라서 °C가 약분됨
$$\frac{Q}{G} = C\,\Delta t \;\Rightarrow\; \left[\frac{\text{kcal}}{\text{kgf}\cdot{}^\circ\text{C}}\right]\times[{}^\circ\text{C}] = \left[\frac{\text{kcal}}{\text{kgf}}\right]$$

한 줄 요약: 비열 = 열량 / (무게 × 온도), 감열·잠열 = 열량 / 무게

감열·잠열은 등압비열에 포함되나?

아니요. 분류 기준이 다른 별개의 개념이에요.

  • 등압비열·등적비열: 어떤 조건에서 가열하나(압력 일정 / 체적 일정)로 나눈 비열 (물질의 성질)
  • 감열·잠열: 가한 열이 무엇에 쓰였나(온도 상승 / 상변화)로 나눈 열량

감열은 두 조건 모두에서 생길 수 있고, 쓰는 비열만 달라요.

$$Q = G\,C_p\,\Delta t\ (\text{등압}) \qquad Q = G\,C_v\,\Delta t\ (\text{등적})$$

교재의 "온도 상승 + 일부 체적 팽창"은 사실상 등압 상황. 다만 액체·고체는 거의 팽창하지 않아 \(C_p \approx C_v\)라서 그냥 "비열"이라 하고, 둘의 차이가 중요한 건 기체.

잠열은 비열로 계산 불가 (\(\Delta t = 0\)이라 \(Q = GC\Delta t\)가 성립 안 함). 대신 정의가 "일정한 압력하에서 전부 증발시키는 열량"이라 등압 조건에서 정의되는 양. 압력이 바뀌면 끓는점도 잠열 값도 바뀜.

열은 에너지의 일종이므로 역학에서 정의한 에너지보존의 법칙(energy conservation law)에 적용함으로써 일과 열을 상호 환산할 수 있다는 법칙. 즉, 열을 일로, 일은 열로 변환할 수 있음을 나타낸 법칙. ★ C4 주관식

에너지보존의 법칙 = 전제조건. 이게 없으면 열역학 1법칙은 성립할 수 X

기계적 일 W를 하여 열량 Q(Quantity of Heat)로 바뀌고, 또 열량 Q가 일 W로 바뀌었다면: 일 = 힘 × 거리

★ 외워
$$Q = AW\ [\text{kcal}] \qquad\text{또는}\qquad W = JQ\ [\text{kgf}\cdot\text{m}]$$
Q ≠ W: 일과 열이 같은 건 아니고 뭘 곱해야 함. 일을 알고 열을 구한다.
A = 일의 열당량 thermal equivalent of work

\(A = \dfrac{1}{427}\) [kcal/kgf·m]

J = 열의 일당량 mechanical equivalent of heat

\(J = 427\) [kgf·m/kcal]

열당량 = 열에 해당하는 양   1 kcal = 427 kgf·m

일의 열당량 계산 유도

$$1\ \text{kgf}\cdot\text{m} = 9.8\ \text{N}\cdot\text{m} = 9.8\ \text{J} = 9.8\times\frac{0.239}{1000}\ \text{kcal} \approx \frac{1}{427}\ \text{kcal}$$

이 값은 줄(Joule)의 실험으로 구했다. 물을 넣은 탱크 안 교반장치를, 무게 G의 추가 높이 z만큼 내려올 때 돌려서 물의 온도상승(발생 열량)을 측정하고, 가한 일 Gz와 비교해 일의 열당량을 결정.

내부에너지와 밀폐계(비유동계)의 에너지식

내부에너지 internal energy, U

그 물체 내에 보유하고 있는 에너지. 즉 물체에 저장된 전체에너지에서 역학적 에너지(위치, 운동에너지)를 제외한 에너지로서, 온도만의 함수이며 상태함수이다.

온도 ↑ → 내부E ↑   온도 ↓ → 내부E ↓

정지한 물체가 외부 열원으로부터 열을 받으면:

  1. 가열량의 일부는 그 물체의 분자운동의 에너지 증가에 쓰이고, 따라서 물체의 온도는 상승하며 감열 또는 현열로서 축적된다.
  2. 온도가 상승함에 따라 체적은 증가한다. 분자 사이 저항력을 이겨 내부적으로 일을 하고 잠열로 축적된다.
  3. 그 물체에 다시 외력에 저항하여 체적이 증가되면 외부에 대해서 기계적 일을 한다.

밀폐계 (팽창과정)

밀폐계는 중량 유동이 없는 상태로서, 예) 왕복운동 내연기관의 팽창과정(= 폭발과정)이라고 생각하면 흡·배기 밸브는 닫혀 있고 피스톤이 팽창하여 일을 얻는 과정이다. 실린더에 미소열량 δQ를 가하면 계의 온도·압력이 증가하고 피스톤이 ds만큼 팽창한다.

에너지보존의 법칙에 의해 단위 중량당 입력 열량과 출력 열량은 같아야 하므로:

입력에너지 = 출력에너지
$$\delta q = de + A\,\delta_1 w_2\ [\text{kcal/kgf}]$$
δ₁w₂: 1 → 2로 일을 했다는 의미. Q = AW (A: 일의 열당량 1/427 kcal/kgf·m)

de는 계의 에너지 변화량(증가량)을 의미한다.

$$de = du + \Delta E_p + \Delta E_k$$

du: 내부에너지, ΔEp: 위치에너지, ΔEk: 운동에너지 변화

여기서 계의 에너지는 위치에너지(Ep: potential energy), 운동에너지(Ek: kinetic energy), 내부에너지(U: internal energy)가 있다.

밀폐계의 종류: 고정 밀폐계 (ΔEp와 ΔEk가 0)와 이동 밀폐계 (ΔEp와 ΔEk 값이 있음). 고정 밀폐계로 생각하면:

$$de = du + \cancel{\Delta E_p} + \cancel{\Delta E_k} \;\Rightarrow\; de = du$$
★ 외워: 열역학 제1법칙의 제1기초식
$$\delta Q = dU + A\,\delta_1 W_2\ [\text{kcal}]$$
일을 열로 바꾸려면 A를 곱해 줘야 함

즉, 계의 에너지는 내부에너지 U만의 함수로 하고 내부에너지는 온도만의 함수로서 온도가 증가(감소)하면 작업유체의 내부에너지도 증가(감소)한다. 따라서 (3)식을 열역학 제1법칙의 제1기초식이라 한다.

내부E는 계의 온도 그 자체이다.

정상유동계(개방계)의 에너지식과 엔탈피

정상유동 steady flow

정의

정상유동이란 유동의 한 점에서 유동의 상태가 시간에 관계없이 일정하게 흐르는 유동을 말한다.

그림 2.4와 같은 정상유동의 관로에 단위 시간당 유체중량 G kgf이 흐르는 경우를 생각한다.

비체적: 같은 무게를 갖고 비교하는 것.
압력비체적비내부에너지속도기준면으로부터 높이
입구 1P₁v₁e₁ω₁Z₁
출구 2P₂v₂e₂ω₂Z₂

계 내에 유입되는 유체가 갖는 에너지 E₁, 유출되는 에너지 E₂는:

식 (4)
$$E_1 = G\Big(e_1 + \underbrace{AP_1v_1}_{\text{일}} + \underbrace{A\frac{\omega_1^2}{2g}}_{\text{운동E}} + \underbrace{AZ_1}_{\text{위치E}}\Big)$$
$$E_2 = G\Big(e_2 + AP_2v_2 + A\frac{\omega_2^2}{2g} + AZ_2\Big)$$
"AP₁v₁"이 왜 일인가?  W = F·S,  P = F/A
Pv = (F/A)·V[m³] = [kgf·m] → Pv는 일이다

이때 계 내에 외부로부터 유체에 Q의 열량이 공급되고, 계가 외부에 대하여 Wt의 일을 한다면:

식 (5) 입력 = 출력
$$E_1 + Q = E_2 + AW_t$$
$$G\Big(e_1 + AP_1v_1 + A\frac{\omega_1^2}{2g} + AZ_1\Big) + Q = G\Big(e_2 + AP_2v_2 + A\frac{\omega_2^2}{2g} + AZ_2\Big) + AW_t$$

단위 중량당 공급열량 \(q = Q/G\), 일량 \(w_t = W_t/G\)라면, 단위 중량당 유동유체에 대하여:

★ 외워: 비엔탈피
$$h = e + APv$$
e: 에너지,  v: 체적,  A: 일의 열당량 (엔탈피도 열량임)

엔탈피 enthalpy

★ 엔탈피: enthalpein = to heat (열을 가하다라는 그리스어) → 기호를 h로 표현

5번식을 G로 나누면:

$$\underbrace{e_1 + AP_1v_1}_{\text{엔탈피 } h_1} + \frac{A}{2g}\omega_1^2 + AZ_1 + q = \underbrace{e_2 + AP_2v_2}_{h_2} + \frac{A}{2g}\omega_2^2 + AZ_2 + Aw_t$$
식 (6) ★ 이 식 잘 기억해
$$\underbrace{h_1 + \frac{A}{2g}\omega_1^2 + AZ_1 + q}_{\text{입구 에너지}} = \underbrace{h_2 + \frac{A}{2g}\omega_2^2 + AZ_2 + Aw_t}_{\text{출구 에너지}}$$

\(\frac{A}{2g}\omega^2\): 운동E,  \(AZ\): 위치E,  \(q\): 입력된 열량,  \(Aw_t\): 밖에 한 일

정의

엔탈피(enthalpy)란 유체의 내부에너지와 이 유체가 일정한 체적을 차지하는 유동일의 합을 정의한다. 즉 내부에너지와 압력, 체적에 대한 유동에너지의 합.

정상유동에서의 에너지식

식 (6)을 단위 중량당의 열량으로 나타내면:

식 (7) 정상유동에서의 에너지식
$$q = (h_2 - h_1) + \frac{A}{2g}(\omega_2^2 - \omega_1^2) + A(Z_2 - Z_1) + Aw_t\ [\text{kcal/kgf}]$$

기준면으로부터의 위치 Z₁, Z₂의 차이가 크지 않고 입출구의 속도차가 크지 않으면, 위치에너지와 운동에너지를 무시해서:

식 (8) ★ 외워
$$q = (h_2 - h_1) + Aw_t$$

식 (8)에서 \(w_t\)를 개방계의 일 또는 공업일(technical work)이라 한다. 일반적으로 정상유동의 에너지방정식은 터빈, 노즐, 펌프 등에 적용하여 이용할 수 있다. → 정상유동 에너지식 응용

P-v 선도와 일

9주차 · 10주차

미소일 δW = PdV

피스톤의 단면적을 A, 압력을 P라 하면 피스톤이 미소량 dx로 변위할 때 피스톤에 F라는 힘이 작용하여 일 δW는:

식 (9)
$$\delta W = F\,dx \;\xrightarrow{F = PA}\; \delta W = PA\,dx \;\xrightarrow{A\,dx = dV}\; \delta W = P\,dV\ [\text{kgf·m}]$$
식의 의미: 미소일은 힘에 미소거리를 곱한 것과 같다.

PdV는 그림 2.5에서 사선부분에 해당하므로, 피스톤이 1에서 2까지 움직이는 사이에 한 일을 ₁W₂로 하면:

식 (10)
$${}_1W_2 = \int_1^2 P\,dV = \text{면적 } 1\text{-}2\text{-}3\text{-}4$$
1~2까지 PdV를 적분한 게 피스톤이 1~2까지 한 일과 같다.

이 일 ₁W₂를 절대일(absolute work) 경계일(boundary work)이라고 한다. → 경계일과 공업일

수업 자료: Boundary work (Wb)

Work caused by the movement of the boundary of a system, such as a piston moving as gas expands or compresses.

$$W_b = \int_{V_1}^{V_2} P\,dV$$
  • 주로 밀폐계(closed system)에 쓴다.
  • 팽창(expansion): 기체가 한 일은 (+)
  • 압축(compression): 기체가 한 일은 (−)

P-v 선도 (일선도)

일정량의 기체의 압력 P와 부피 V를 직교좌표의 양축으로 하여 상태변화를 나타내는 선도를 P-v 선도 (v: 비체적), 또는 선도의 면적은 가역변화인 경우에 일을 나타내므로 일선도라고도 한다.

가역변화: 원래의 상태로 다시 되돌아갈 수 있을 때. (feat. p.5) → 상태변화 페이지

가역변화에서의 제1기초식

가역변화에서는 식 (10)이 성립하고, 열역학 제1법칙의 제1기초식 (3) \(\delta Q = dU + A\,\delta_1W_2\)은:

식 (11) 대문자: 질량·중량이 포함됨
$$\delta Q = dU + AP\,dV = G(de + AP\,dv)$$
$${}_1Q_2 = (U_2 - U_1) + A\int_1^2 P\,dV$$

혹은 단위중량의 기체에 대해서는 비체적 = 체적/중량 또는 체적/질량

식 (12), (13)
$$\delta q = de + AP\,dv \qquad\Longrightarrow\qquad {}_1q_2 = (e_2 - e_1) + A\int_1^2 P\,dv$$

제2기초식 (엔탈피 형태)

만일 비엔탈피 h를 사용하여 미분형으로 나타내면 \(dh = de + A(v\,dP + P\,dv)\)가 되므로:

필기: 유도 과정
$$h = e + APv \;\xrightarrow{\text{미분}}\; dh = de + A(v\,dP + P\,dv)$$
$$de = dh - A(v\,dP + P\,dv) \;\xrightarrow{\text{12번식에 대입}}\; \delta q = dh - A(v\,dP + \cancel{P\,dv}) + \cancel{AP\,dv}$$
식 (14) ★ 열역학 제1법칙의 제2기초식
$$\delta q = dh - Av\,dP$$
식 (15)
$${}_1q_2 = (h_2 - h_1) - A\int_1^2 v\,dP$$

식 (15)를 등압변화에 이용하면 (dP = 0이라 적분항이 사라짐) \({}_1q_2 = h_2 - h_1\)이 된다.

경계일 boundary work

처음에 피스톤이 위치 1에 있을 때 P-v 선도 상에서 점 1, 피스톤 내 기체가 팽창하여 위치 2로 이동하면 점 2가 된다.

이때 기체가 외부에 하는 일 W는 식 (10)으로 표시하며, 1-2구간 곡선의 밑면적 1-2-V₂-V₁과 같다. 다음에 상태 2에서 상태 1로 되돌아올 때, 만일 동일곡선을 따라 되돌아오면 동일한 일이 외부로부터 기체에 흡수되게 된다.

이와 같이 밀폐계가 준정적 변화에 따라 하게 되는 일을 경계일(boundary work)이라 하며 식 (10)으로 표시된다.

$$W_t = -\int_1^2 V\,dP\ [\text{kgf·m}] \quad\text{(중량이 반영된 식)}$$
$$w_t = -\int_1^2 v\,dP\ [\text{kgf·m/kgf}] \quad\text{(단위중량당 한 일)}$$

Technical work (flow work output): work associated with a flowing fluid passing through a machine, such as a turbine or compressor. For a reversible steady-flow process (work output positive):

$$w_t = -\int_{P_1}^{P_2} v\,dP$$

$$H_1 + AG\frac{\omega_1^2}{2g} + AGZ_1 + Q = H_2 + AG\frac{\omega_2^2}{2g} + AGZ_2 + AW_t$$

기기마다 어떤 항을 무시하는지만 다르다.

(1) 압축기

압축기를 통과하는 유동은 압축기에서 하는 일이 행하여지고, 열손실(냉각수)이 되고, 1과 2 상태의 차이가 무시할 수 있는 운동에너지와 위치에너지는 0이 되므로 일반에너지식에서:

$$H_1 + \cancel{AG\frac{\omega_1^2}{2g}} + \cancel{AGZ_1} + Q = H_2 + \cancel{AG\frac{\omega_2^2}{2g}} + \cancel{AGZ_2} + AW_t$$
식 (19) 중량이 포함된 식
$$Q = AW_t + (H_2 - H_1)\ [\text{kcal}]$$

터빈을 통과하는 유동에서 터빈의 일은 발전기에 의해 행하고, 근사적으로 가열량, 위치에너지, 운동에너지 등을 무시한다고 하면:

  1. 84.7
  2. 78.5
  3. 107.8
  4. 93.5

㉱ 93.5 ℃

동력 \(W = \frac{2\pi nT}{60}\) [kgf·m/s], 물 0.5 ℓ/s = 0.5 kgf/s, C = 1:
