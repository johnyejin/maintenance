열응력 (Thermal Stress)

온도 변화에 의해 발생하는 응력 — 변형 억제가 핵심

개념

왜 열을 가하면 응력이 생기나?

재료에 열이 가해지면 원자의 진동에너지가 증가하고, 진동의 폭이 커지면서 원자들 사이의 평균 거리가 멀어진다 → 재료가 팽창한다.

핵심 구분: 변형이 자유롭게 허용되면 응력은 발생하지 않는다. 변형이 외부에 의해 억제되어야 비로소 열응력이 발생한다. 예) 벽에 고정된 봉, 철도 레일

①

선팽창계수 α (Coefficient of Linear Expansion)

온도가 1°C 변화할 때 원래 길이에 대한 길이 변화 비율

선팽창계수 정의
\[ \alpha = \frac{\Delta L / L}{\Delta t} \quad \Rightarrow \quad \frac{\Delta L}{L} = \alpha \cdot \Delta t \]
ℹα가 클수록 같은 온도 변화에도 더 많이 늘어난다. 단위: /°C 또는 /K. α는 재료 고유의 성질이다.
②

열변형량 δ (Thermal Deformation)

균일 단면, 균질 재료의 봉이 온도 ΔT 변화할 때 늘어나는 길이:

열변형량
\[ \delta_T = L \cdot \alpha \cdot \Delta T \]
기호의미단위
δT열에 의한 변형량 (늘어난 길이)m, mm
L봉의 원래 길이m, mm
α선팽창계수/°C
ΔT = t₂ − t₁온도 변화량°C
③

열응력 σ 유도 시험 핵심

봉이 양쪽에 고정되어 있어서 팽창을 못 하는 상황을 생각하자.

양단 고정 봉에 열이 가해질 때 — 팽창이 억제되면 압축응력 발생

유도: 자유 열변형량 = 반력에 의한 변형량 (실제 변형 = 0)

변형 적합 조건
\[ \delta_T = L\alpha\Delta T = \delta_P = \frac{PL}{AE} \]

P/A (응력)로 정리하면:

열응력 (Thermal Stress)
\[ \sigma = E \alpha \Delta T \]
⚠주의: 응력(σ)은 길이 L과 무관하다. 변형량(δ = LαΔT)은 L에 비례. 이 차이를 반드시 구분할 것.
✓온도 상승 → 팽창 억제 → 압축응력 / 온도 하강 → 수축 억제 → 인장응력
④

열반력 P

고정된 봉에서 발생하는 반력:

\[ P = \sigma A = E \alpha \Delta T \cdot A = EA\alpha(t_2 - t_1) \]

얇은 압력용기 (Thin-Walled Pressure Vessel)

내압을 받는 원통·구형 용기 — 후프응력이 축응력의 2배

기본

기본 가정 및 설계 목표

압력용기 설계 시 결정할 것: ① 면적(단면), ② 두께

두께 t가 안지름 d보다 훨씬 작을 때(t ≪ d, 보통 t/d < 1/20) → 두께 방향 응력이 균일하다고 가정.

ℹ설계 흐름: 내압 p와 지름 d로 두께 t를 결정. 두 방향(원주 방향, 축 방향)으로 응력을 각각 계산한다.
①

원통형 압력용기의 두 응력 시험 핵심

FBD(자유물체도)를 이용한 힘 균형으로 응력 유도

후프응력 (원주방향, Hoop Stress)

\[ \sigma_\theta = \frac{pd}{2t} \]
  • 원통이 세로로 쪼개지려는 힘에 저항
  • 더 큰 응력 → 설계 기준

축방향응력 (세로방향)

\[ \sigma_x = \frac{pd}{4t} = \frac{1}{2}\sigma_\theta \]
  • 뚜껑 면을 밀어내는 힘에 저항
  • 후프응력의 절반
⚠핵심: σ_θ = 2σ_x. 원통 압력용기는 원주방향이 2배 더 위험하다. 소시지 껍질이 세로로 터지는 이유.
②

두께 설계 공식 (실무)

허용응력 σallow을 기준으로 최소 두께 산정:

\[ t = \frac{pD}{2\sigma_{allow}} + 1\text{ mm (부식여유)} \]
③

구형 압력용기

구는 어느 방향으로 잘라도 대칭 → 응력이 모든 방향에서 동일:

\[ \sigma = \frac{pd}{4t} \]

구형이 원통형보다 구조적으로 효율적이다 (같은 내압에서 응력이 절반).

④

잔류응력 (Residual Stress)

너트를 꽉 조이면 풀림 방지되는 이유: 접촉면에 압축잔류응력이 발생하기 때문.

ℹ잔류응력: 외부하중 제거 후에도 재료 내부에 남아있는 응력. 압축잔류응력 → 피로수명 증가 / 인장잔류응력 → 피로수명 감소.

회전하는 얇은 원환체 (Rotating Thin Ring)

원운동 기초부터 원심응력까지 — 엔진 회전 부품 설계의 핵심

①

등속 원운동 기초 기초

등속 직선운동

  • 가속도 a = 0
  • 속도 v = 일정
  • 힘 F = 0

등속 원운동

  • 각가속도 α = 0
  • 각속도 ω = 일정
  • 속력 v = rω = 일정 (방향은 변함)
  • 구심가속도 ac = v²/r
  • 토크 τ = 0
  • 구심력 F = mv²/r
⚠등속 원운동에서 속력은 일정하지만 방향이 바뀌므로 속도(벡터)는 변한다 → 가속도 존재 → 구심 방향.
②

각도·호·속도 관계식

호의 길이 (반드시 라디안)
\[ l = r\theta \]
선속도 = 반지름 × 각속도
\[ v = r\omega \]
각속도, 주기, 진동수
\[ \omega = \frac{2\pi}{T} = 2\pi f \]
RPM → 각속도 (N: 분당 회전수)
\[ \omega = \frac{2\pi N}{60} \text{ [rad/sec]}, \quad v = \frac{\pi d N}{60} \text{ [m/sec]} \]
③

구심가속도 유도 — 이등변삼각형 닮음 시험 원리

위치벡터 삼각형과 속도벡터 삼각형이 모두 꼭짓각 Δθ의 이등변삼각형 → 닮음:

\[ \frac{\Delta r}{r} = \frac{\Delta v}{v} \quad \Rightarrow \quad \Delta v = \frac{v}{r}\Delta r \]
구심가속도
\[ a_c = \frac{\Delta v}{\Delta t} = \frac{v}{r} \cdot \frac{\Delta r}{\Delta t} = \frac{v^2}{r} = r\omega^2 \]
✓Δv의 방향이 항상 중심 방향 → 구심가속도. 속력 변화 ≠ 속도 변화.

구심력

\[ F = ma_c = mr\omega^2 = m\frac{v^2}{r} \]

항상 중심 방향으로 작용. 속력을 변화시키지 않는다 (운동 방향에 수직 → 일 = 0).

④

회전 원환체의 원심응력 시험 핵심

RPM으로 회전하는 링에는 원심력으로 인해 내부에 인장응력이 생긴다.

원심응력 (γ: 단위중량 [kgf/m³])
\[ \sigma_\theta = \frac{\gamma v^2}{g} = \frac{\gamma r^2\omega^2}{g} = \frac{\gamma\pi^2 d^2 N^2}{60^2 g} \]
ℹ응력 ∝ v² → RPM이 2배가 되면 응력은 4배. 이것이 엔진 부품의 RPM 한계가 중요한 이유이다.
⑤

원운동 핵심 성질 & 인공위성

  • 구심력은 속력을 증가시키지 못한다 (운동 방향에 수직 → 일 = 0)
  • 일정 구심력 → 등속 원운동
  • 속력을 바꾸려면 접선방향 힘(토크)이 필요: F_θ = mrα
  • 인공위성: 중력(구심력)과 원심 효과 균형 → 토크 = 0 → 각운동량 보존 → 계속 회전

탄성에너지 (Strain Energy)

하중-변형 그래프 아래 면적 = 재료에 저장된 에너지

①

탄성에너지의 개념

물체에 하중 작용 → 변형 → 변형에너지가 탄성한도 내에서 재료 내부에 저장 → 하중 제거 시 복원

P-δ 그래프 아래 삼각형 면적 = 저장된 탄성에너지 U

②

수직력에 의한 탄성에너지 시험 핵심

후크의 법칙 성립 범위에서 P-δ 선형 → 에너지 = 삼각형 면적:

탄성에너지 (전체)
\[ U = \frac{1}{2}P\delta = \frac{P^2 L}{2AE} = \frac{\sigma^2 AL}{2E} = \frac{\sigma^2 V}{2E} \]
단위 체적당 탄성에너지 (Resilience, u)
\[ u = \frac{U}{V} = \frac{\sigma^2}{2E} = \frac{E\varepsilon^2}{2} = \frac{\sigma\varepsilon}{2} \]
⚠식 변환 핵심: σ = Eε, δ = PL/(AE), P = σA, V = AL — 이 관계를 자유롭게 대입해 변환할 줄 알아야 한다.
ℹ레질리언스(Resilience): 탄성한도 내 단위 체적당 저장 가능한 탄성에너지 최대량. 재료의 에너지 흡수 능력.
③

전단력에 의한 탄성에너지

수직응력 σ → τ, E → G(전단탄성계수), ε → γ(전단변형률)로 대체:

\[ U = \frac{\tau^2 V}{2G} = \frac{AG\gamma^2 L}{2}, \quad u = \frac{\tau^2}{2G} = \frac{G\gamma^2}{2} = \frac{\tau\gamma}{2} \]

경사단면 위에서의 1축 응력

축하중을 받는 봉의 경사단면에서 수직응력과 전단응력 분석

①

기본 설정 및 FBD

봉에 축방향 하중 P가 작용할 때, θ만큼 기울어진 경사단면에서의 응력을 구한다.

경사각 θ인 단면에서 P를 법선분력 N과 접선분력 T로 분해

분력 분해 및 경사 면적
\[ N = P\cos\theta,\quad T = P\sin\theta,\quad A' = \frac{A}{\cos\theta} \]
②

경사단면 응력 공식 유도 시험 핵심

수직응력 (법선응력)
\[ \sigma_\theta = \frac{N}{A'} = \frac{P\cos\theta}{A/\cos\theta} = \sigma_x \cos^2\theta \]
전단응력
\[ \tau_\theta = \frac{T}{A'} = \frac{P\sin\theta}{A/\cos\theta} = \frac{1}{2}\sigma_x\sin 2\theta \]
각도 θσ_θτ_θ
0° (수직단면)σ_x (최대)0
45°σ_x/2σ_x/2 (최대 전단응력)
90° (평행단면)00
ℹ최대 전단응력은 45° 단면에서 발생 (크기: σ_x/2). 연성재료의 파단면이 45°인 이유.
③

보완응력 (Complementary Stress)

θ' = θ + 90° 방향 단면에서:

\[ \sigma_{\theta'} = \sigma_x\sin^2\theta, \quad \tau_{\theta'} = -\tau_\theta \]

서로 수직인 두 단면의 전단응력은 크기가 같고 방향이 반대 → 짝힘(쌍)으로 작용

합 관계
\[ \sigma_\theta + \sigma_{\theta'} = \sigma_x(\cos^2\theta + \sin^2\theta) = \sigma_x \]

충격하중에 의한 응력과 변형률

에너지 보존으로 유도 — 갑자기 가해도 정적의 2배

①

충격하중이란?

물체가 갑작스러운 충돌이나 하중을 받을 때 발생하는 응력. 정적 하중보다 훨씬 크며, 운동에너지가 순간적으로 재료의 변형에너지로 전환된다.

💥충격하중 응력 ≥ 정적 하중 응력의 2배. 충격 시간(Δt)이 짧을수록 힘이 더 커진다 (충격량 = 힘 × 시간 = 일정).
②

에너지 보존으로 충격응력 유도 시험 핵심

무게 W인 물체가 높이 h에서 봉 위로 낙하할 때:

무게 W가 높이 h에서 낙하 → 봉이 δ만큼 압축

\[ W(h + \delta) = \frac{AE\delta^2}{2l} \]

이차방정식으로 풀면 (δst = Wl/AE, σst = W/A):

충격 최대 변형량
\[ \delta = \delta_{st}\left(1 + \sqrt{1 + \frac{2h}{\delta_{st}}}\right) \]
충격응력
\[ \sigma = \sigma_{st}\left(1 + \sqrt{1 + \frac{2h}{\delta_{st}}}\right) \]
⚠괄호 안 (1 + √…)가 충격계수(Impact Factor). 항상 1보다 크므로 충격응력 > 정적응력.
③

근사값 공식 및 특수 경우

h ≫ δ인 경우 (δ 무시 가능):

h ≫ δ 근사
\[ \sigma \approx \sqrt{\frac{2EWh}{Al}} \]

h = 0인 경우 (갑자기 올려놓는 경우):

h = 0 급하중
\[ \delta = 2\delta_{st}, \quad \sigma = 2\sigma_{st} \]
✓낙하 높이 = 0이어도 정적 응력의 2배! 이것이 동적 하중이 위험한 이유이다.

충격계수 (Impact Factor)

\[ \text{충격계수} = \frac{\delta_{max}}{\delta_{st}} = 1 + \sqrt{1 + \frac{2h}{\delta_{st}}} \]

구조물의 정적 반응에 대한 동적 반응의 비율. 설계 허용응력 결정에 활용.

단면 모멘트 & 도심

단면 1·2차 모멘트의 개념, 목적, 원리

①

단면 모멘트란? — 왜 필요한가

구조물의 변형·저항 능력은 재료의 성질뿐만 아니라 단면의 형상에도 좌우된다.

"모멘트(moment)"라는 말 자체가 어떤 물리량에 거리를 곱한다는 의미다. (예: 힘의 모멘트 M = F × d)

단면 1차 모멘트 Q

면적(dA)에 거리를 1제곱 곱한 뒤 적분

→ 목적: 도심(무게중심 위치) 찾기

단위: mm³ (면적 × 거리)

단면 2차 모멘트 I

면적(dA)에 거리를 2제곱 곱한 뒤 적분

→ 목적: 굽힘·저항 능력 파악 (강성)

단위: mm⁴ (면적 × 거리²)

ℹ핵심 원리: 같은 재료라도 단면 형상을 바꾸면 강도가 달라진다. 축에서 멀수록(거리가 클수록) 모멘트에 더 크게 기여 → 축과 멀리 배치하는 게 유리.
②

단면 1차 모멘트 Q (First Moment of Area) 시험 핵심

정의 & 수식

임의의 축으로부터 미소 면적(dA)까지의 거리를 곱하여 전체 면적에 대해 적분한 값.

x축에 대한 단면 1차 모멘트
\[ Q_x = \int_A y \, dA = A \cdot \bar{y} \]
y축에 대한 단면 1차 모멘트
\[ Q_y = \int_A x \, dA = A \cdot \bar{x} \]
⚠Q는 축의 위치에 따라 양수·음수 모두 가능. 2차 모멘트(I)와 다르게 음수가 나올 수 있다 — I는 거리²이라 항상 양수.
✓단위: mm³ (또는 m³) — 면적(mm²) × 거리(mm) = mm³. 헷갈리면 면적 × 거리 = 세제곱으로 기억.

Q의 물리적 의미 — 왜 쓰는가?

Q 자체는 구조적 강성을 직접 나타내지 않는다. 면적의 중심 위치(도심)를 결정하는 수학적 도구다.

도심 좌표 유도
\[ \bar{x} = \frac{Q_y}{A}, \qquad \bar{y} = \frac{Q_x}{A} \]

또한 보(beam)의 전단응력 계산에도 Q가 등장한다 — 후속 챕터에서 활용.

③

도심(Centroid) 시험 핵심

도심이란?

도형이나 물체의 기하학적 중심점. 질량이 균일하게 분포한다고 가정할 때 무게중심(Center of Gravity)과 같은 위치.

도심은 도형을 구성하는 모든 미소 면적(또는 부피)의 평균 위치라고 할 수 있다.

✓중요한 성질: 도심을 지나는 축에 대한 단면 1차 모멘트 Q = 0. 덧심(centroid)은 항상 대칭축 위에 존재.

기본 도형별 도심 공식 암기

도형\(\bar{x}\)\(\bar{y}\)면적 A
직사각형 (너비 b, 높이 h)\(\dfrac{b}{2}\)\(\dfrac{h}{2}\)\(bh\)
삼각형 (밑변 b, 높이 h)\(\dfrac{b}{3}\)\(\dfrac{h}{3}\)\(\dfrac{bh}{2}\)

ℹ 삼각형 도심 = 중선의 1:2 내분점 = 밑변으로부터 h/3. 꼭짓점이 아닌 밑변 쪽에 더 가깝다.
반원 도심 = 원의 중심에서 수직으로 4r/3π 만큼 떨어진 지점 (원주 쪽으로 치우침).

복합 도형의 도심 — 분할 가중평균법 시험 출제

복잡한 단면 → 기본 도형으로 분할 후 면적 가중평균. 구멍은 음수 면적으로 처리.

복합 도형 도심 (n개 부분 도형)
\[ \bar{x} = \frac{\sum_{i=1}^n A_i \bar{x}_i}{\sum_{i=1}^n A_i}, \qquad \bar{y} = \frac{\sum_{i=1}^n A_i \bar{y}_i}{\sum_{i=1}^n A_i} \]
ℹ풀이 순서: ① 기본 도형 분할 ② 각 도형의 A, x̄, ȳ 계산 ③ A·x̄, A·ȳ 합산 ④ 총면적으로 나눔

단면 2차 모멘트 I — 개념 이해 시험 핵심

왜 "2차"인가? — 원리부터

보(beam)에 굽힘모멘트 M이 작용할 때, 내부적으로 어떤 일이 벌어지는지 생각해보자.

보에 굽힘 발생 시: 중립축 기준으로 바깥쪽이 가장 큰 힘을 받는다 → 바깥쪽에 단면적을 집중시키면 효율적 (I형강 원리)

단면 2차 모멘트 (관성 모멘트)
\[ I_x = \int_A y^2 \, dA, \qquad I_y = \int_A x^2 \, dA \]

단위: mm⁴ — 면적(mm²) × 거리²(mm²)

⚠I는 거리의 제곱이 붙기 때문에 항상 양수. 높이 h가 세제곱으로 작용 → 높이에 매우 민감. 같은 단면적이라도 높이를 늘리는 것이 훨씬 효과적.
✓I형강(H빔)이 효율적인 이유: 가장 큰 힘을 받는 위아래 플랜지에 면적을 집중 배치 → I 값은 크게 유지하면서 재료는 절약.

평행축 정리 (Parallel Axis Theorem) 시험 핵심

왜 필요한가?

복합 단면(T형, I형 등)의 2차 모멘트를 구할 때, 각 부분 도형의 도심축이 전체 도형의 도심축과 다르다. 축을 이동시킬 때 I가 어떻게 변하는지 알아야 한다.

평행축 정리 — 핵심 공식
\[ I = \bar{I} + A d^2 \]
기호의미
\(I\)도심과 평행한 새 축에 대한 단면 2차 모멘트
\(\bar{I}\)각 부재 구성 요소의 도심축에 대한 단면 2차 모멘트
\(A\)해당 부분 도형의 면적
\(d\)도심축과 새 축 사이의 수직 거리
ℹ원리 이해: 축을 d만큼 이동시키면 Ad² 만큼 추가로 발생. 거리²에 면적을 곱한 것 — 이게 "축 이동에 의한 추가 관성 모멘트"다. 항상 도심축 I보다 크거나 같다.

평행축 정리 유도 — 왜 Ad²인가?

도심 C를 지나는 BB'축 기준 I가 \(\bar{I}\)일 때, 거리 d만큼 떨어진 AA'축에 대한 I를 구하면:

\[ I_{AA'} = \int_A (y + d)^2\,dA = \int_A y^2\,dA + 2d\int_A y\,dA + d^2\int_A dA \]

여기서 중간 항 \(\int_A y\,dA\) = 도심축에 대한 Q → 도심을 지나므로 Q = 0.

\[ \therefore I_{AA'} = \bar{I} + d^2 A \]
✓Q = 0이 되는 이유가 평행축 정리의 핵심! 도심축에서만 1차 모멘트가 사라지기 때문에 이 정리가 성립한다.

T형 단면(플랜지 40×10mm, 웹 10×30mm)에서 X축(밑변)에 대한 I 계산:

부분계산결과
① 플랜지 (flange)
평행축 정리 적용		\(I_{x1} = \frac{40\times10^3}{12} + (40\times10)\times35^2\)≈ 493,333 mm⁴
② 웹 (web)
밑변축 직접 적용		\(I_{x2} = \frac{10\times30^3}{3}\)= 90,000 mm⁴

관성반경 k & 단면계수 Z

관성반경 (Radius of Gyration) k

"같은 단면 2차 모멘트 I를 가지면서, 면적 전체를 하나의 선(거리 k)에 집중시켰을 때의 거리" — 단면의 효율적인 분포 반경.

\[ k_x = \sqrt{\frac{I_x}{A}}, \qquad k_y = \sqrt{\frac{I_y}{A}} \]

직사각형의 경우: \(k_x = \sqrt{\frac{bh^3/12}{bh}} = \sqrt{\frac{h^2}{12}} = \frac{h}{\sqrt{12}} = \frac{h}{2\sqrt{3}}\)

단면계수 (Section Modulus) Z

단면 2차 모멘트 축으로부터 가장 먼 섬유(바깥쪽 가장자리)까지의 거리 e로 나눈 값. 굽힘응력 계산에 직접 사용.

\[ Z_{x_1} = \frac{I_x}{e_1}, \qquad Z_{x_2} = \frac{I_x}{e_2} \]

대칭 단면이면 \(Z_{x_1} = Z_{x_2} = Z_x\).

ℹ직사각형(대칭 단면): e = h/2이므로 \(Z_x = \frac{bh^3/12}{h/2} = \frac{bh^2}{6}\). 굽힘응력 \(\sigma = M/Z\)로 최대 응력을 간단히 계산 가능.

단면 극관성 모멘트 J (Polar Moment of Inertia) 시험 핵심

극관성 모멘트란?

비틀림(torsion)에 대한 저항을 나타내는 물리량. 원점 O를 중심으로 한 2차원 거리 r을 사용.

\[ J_O = \int_A r^2\,dA, \qquad r^2 = x^2 + y^2 \]
핵심 관계식 (수직축 정리)
\[ J_O = I_x + I_y \]
ℹ유도: \(J_O = \int r^2 dA = \int (x^2+y^2)dA = \int x^2 dA + \int y^2 dA = I_y + I_x\). 두 방향의 2차 모멘트를 더하면 극관성 모멘트.
⑤

원형 단면축의 비틀림 시험 핵심

비틀림의 특성

비틀림에서는 인장·압축이 아니라 전단응력(τ)이 발생. 따라서 전단탄성계수 G를 사용한다.

✓응력은 반지름에 비례 → 바깥쪽 표면에서 최대 전단응력 발생 (안쪽이 먼저 굵어지기 시작하는 스프링과 달리 단면 내부는 더 안전).

핵심 비틀림 공식

전단응력 (임의 반지름 r에서)
\[ \tau = \frac{Tr}{I_p} \]
최대 전단응력 (표면, r = d/2에서)
\[ \tau_{max} = \frac{T \cdot (d/2)}{I_p} = \frac{16T}{\pi d^3} \quad \text{(중실축)} \]
비틀림각 φ
\[ \phi = \frac{Tl}{GI_p} \]
기호의미
T토크 (비틀림 모멘트)
r중심에서 해당 지점까지 반지름
I_p극관성 모멘트
l축의 길이
G전단탄성계수
⚠비례 관계만 알면 풀 수 있다: τ ∝ T, τ ∝ r, τ ∝ 1/I_p. φ ∝ T·l, φ ∝ 1/(G·I_p)

중실축 vs 중공축 극관성 모멘트

중실축 (Solid Shaft)

\[ I_p = \frac{\pi d^4}{32} \]
\[ \tau_{max} = \frac{16T}{\pi d^3} \] \[ \phi = \frac{32Tl}{\pi d^4 G} \]

중공축 (Hollow Shaft)

\[ I_p = \frac{\pi}{32}(d_o^4 - d_i^4) \]
\[ \tau_{max} = \frac{16Td_o}{\pi(d_o^4 - d_i^4)} \]
✓중공축이 중실축보다 같은 무게에서 더 큰 비틀림 저항 — 안쪽 재료는 응력이 작아 비효율적이므로, 빼도 강성 손실이 적다.

전달 동력 P = Tω

토크 T가 작용하고 각속도 ω로 회전하는 전동축의 전달동력:

코일 스프링 (Coil Spring)

코일 스프링에 작용하는 힘

코일 스프링에 하중 P가 작용하면 선재(wire) 단면에는 비틀림 + 직접 전단력 두 가지가 동시에 작용한다.

토크 T에 의한 전단응력

\[ \tau_1 = \frac{T(d/2)}{I_p} = \frac{PR(d/2)}{\pi d^4/32} = \frac{16PR}{\pi d^3} \]

하중 P에 의한 직접 전단응력

\[ \tau_2 = \frac{P}{A} = \frac{P}{\pi d^2/4} = \frac{4P}{\pi d^3} \]
합성 최대 전단응력 (선재 안쪽 m면에서 발생)
\[ \tau_{max} = \tau_1 + \tau_2 = \frac{16PR}{\pi d^3} + \frac{4P}{\pi d^3} = \frac{16PR}{\pi d^3}\left(1 + \frac{d}{4R}\right) \]
ℹ두 응력이 선재 안쪽(m면)에서 같은 방향으로 합산 → 스프링은 안쪽 면에서 먼저 파손된다.

보(Beam)란?

보(beam): 수평으로 지지되어 수직하중을 받는 기계요소. 단면에 비해 길이가 월등히 길고, 축 방향에 수직한 하중을 받아 굽힘(bending)이 발생한다.

보에서 중요한 것 3가지

전단력 (Shear Force) — 보를 잘라내려는 힘

굽힘모멘트 (Bending Moment) — 보를 굽히는 힘

반력 (Reaction) — 지지점에서 발생하는 힘

보의 특징

전체 흐름

하중 → 전단력 · 굽힘모멘트 → 응력 · 변형률 · 처짐 → 여러 하중 조건 하에서 해석 및 설계

  3. 응력 · 변형률 · 처짐 산출 — V·M으로부터 굽힘응력 \(\sigma = My/I\), 전단응력, 그리고 굽힘각·곡률·변형을 이용해 처짐(δ)을 계산.

  5. 다중 하중 조건 검토 — 여러 하중 조합(최악 조건)에서 안전한지 반복 검증.
★가장 중요 — 보 설계의 출발점은 내부 전단력(V)과 굽힘모멘트(M)를 먼저 아는 것이다. V와 M을 알아야 응력·처짐을 구할 수 있고, 그래야 비로소 단면의 형상·치수(결과)를 정할 수 있다.
✓굽힘각·곡률·변형을 이용해 처짐(에너지)을 계산한다 — 처짐 해석은 곡률 \(1/\rho = M/EI\)에서 출발한다.

단순보 반력 계산 (FBD 활용) 시험 출제

풀이 순서

  1. FBD(자유물체도) 그리기 — 모든 외력과 반력을 표시
  2. 평형방정식 3개 세우기: ΣFx=0, ΣFy=0, ΣM=0
  3. 한 지점을 기준으로 모멘트 방정식 → 반력 하나 먼저 결정 (A점 기준이면 A점 모멘트 반력 = 0)
  4. 나머지 반력 계산

예제 — 집중하중 P가 거리 a에 작용하는 단순보

전체 길이 l인 단순보에 하중 P가 A점에서 거리 a인 C점에 작용.

평형조건 적용
\[ \Sigma F = 0 : \quad R_A + R_B - P = 0 \quad \cdots (1) \] \[ \Sigma M_A = 0 : \quad R_B \cdot l - P \cdot a = 0 \quad \cdots (2) \]
반력 계산
\[ R_B = \frac{Pa}{l}, \qquad R_A = \frac{Pb}{l} \quad (b = l - a) \]
ℹA점을 기준으로 모멘트를 취하면 A점 반력의 모멘트 팔이 0이 되어 방정식이 간단해진다 → 기준점은 항상 미지수가 있는 지점으로 잡는다.

하중 w · 전단력 V · 굽힘모멘트 M 관계식 시험 핵심

핵심 미분 관계

미소 구간 dx에 대한 FBD 분석으로 유도:

전단력과 분포하중의 관계
\[ \frac{dV}{dx} = -w \]
굽힘모멘트와 전단력의 관계
\[ \frac{dM}{dx} = V \]
관계의미
w → 적분 → V분포하중을 적분하면 전단력 (부호 반전)
V → 적분 → M전단력을 적분하면 굽힘모멘트
V를 미분 → −w전단력 기울기 = −분포하중
M을 미분 → V굽힘모멘트 기울기 = 전단력
⚠3가지 경우의 의미를 알면 됨:
① 분포하중 구간: dV/dx = −w → V는 1차, M은 2차
② 집중하중 작용점: V가 불연속으로 점프 (크기 = 집중하중), M은 연속이지만 기울기 변화
③ 집중모멘트 M₀ 작용점: V 변화 없음, M이 불연속으로 점프

적분 공식

전단력 — 시작점 V₀에서 x까지
\[ V = V_0 - \int_{x_0}^{x} w\,dx \]
굽힘모멘트 — 시작점 M₀에서 x까지
\[ M = M_0 + \int_{x_0}^{x} V\,dx \]

V₀, M₀는 시작점(반력이 있는 점)에서의 값. 외팔보의 고정단처럼 M₀ ≠ 0인 경우 주의.

전단력 선도(SFD)와 굽힘모멘트 선도(BMD) 시험 출제

SFD & BMD란?

보의 각 단면에서 발생하는 전단력 V(x)와 굽힘모멘트 M(x)의 변화를 그래프로 나타낸 것.

선도영문 약자하중 종류별 형상
전단력 선도SFD (Shear Force Diagram)집중하중→수평선 / 균일분포→기울기 직선 / 삼각형분포→2차 곡선
굽힘모멘트 선도BMD (Bending Moment Diagram)집중하중→직선 / 균일분포→포물선(2차) / 삼각형분포→3차 곡선
✓핵심 규칙:
· SFD에서 전단력(+) 구간 → BMD 기울기(+기울기, 상승)
· SFD에서 전단력(−) 구간 → BMD 기울기(−기울기, 하강)
· V = 0인 점에서 M이 최대 (또는 최솟값) ← 시험에서 Mmax 구하는 핵심
ℹ최대 굽힘모멘트는 전단력이 부호가 바뀌는 위치 (V = 0인 지점)에서 발생한다. SFD 먼저 그리고, V = 0 위치를 찾아 M값을 계산.

예제① — 집중하중, 단순보 (SFD & BMD)

단순보(길이 l)에 집중하중 P가 A에서 a, B에서 b 위치에 작용:

\[ R_A = \frac{Pb}{l}, \quad R_B = \frac{Pa}{l} \]

구간별 V, M:

① 0 ≤ x ≤ a 구간
\[ V = R_A = \frac{Pb}{l}, \qquad M = R_A x = \frac{Pb}{l}x \]
② a < x ≤ l 구간
\[ V = R_A - P = -\frac{Pa}{l}, \qquad M = \frac{Pa}{l}(l - x) \]
✓SFD: 상수(수평선) → BMD: 1차 직선. 집중하중 작용점에서 V가 불연속으로 점프. 최대 M은 하중 작용점 C에서 발생 (V=0인 지점).

예제② — 균일분포하중, 단순보 (SFD & BMD)

단순보(길이 l)에 균일분포하중 w[N/m] 작용:

\[ R_A = R_B = \frac{wl}{2} \]
전단력 V (1차 함수)
\[ V = \frac{wl}{2} - wx = w\!\left(\frac{l}{2} - x\right) \]
굽힘모멘트 M (2차 함수, 포물선)
\[ M = \frac{w}{2}(lx - x^2) \]
최대 굽힘모멘트 — 중앙(V=0인 점, x=l/2)에서
\[ M_{max} = \frac{wl^2}{8} \]
✓SFD: 1차 기울기 직선 (중앙에서 V=0). BMD: 2차 포물선 (중앙에서 최대). 도심에서 전단력 = 0.

세장비란?

기둥의 길이 L과 최소 단면 2차 반경 r의 비. 기둥이 얼마나 가늘고 긴지를 나타내는 무차원 지표.

세장비 (Slenderness Ratio)
\[ \lambda = \frac{L}{r}, \qquad r = \sqrt{\frac{I_{min}}{A}} = k \text{ (관성반경)} \]
기둥 종류세장비 범위파괴 형태
단주 (Short column)\(0 < \dfrac{L}{r} < 50\)압축 파괴 (재료 강도 지배)
중간주\(50 \leq \dfrac{L}{r} < 100\)중간 영역
장주 (Long column)\(\dfrac{L}{r} \geq 100\)좌굴 파괴 (기하학적 불안정)
⚠세장비가 클수록 좌굴에 저항하는 능력이 작아진다. 같은 재료라도 세장하면 훨씬 낮은 하중에서 파괴됨. I, r이 클수록(단면을 축에서 멀리) 세장비 감소 → 좌굴 저항 증가.
③

좌굴 현상 (Buckling) 시험 핵심 ②

좌굴이란?

탄성 재료로 된 장주에 축방향 압축력 P를 가할 때, 임계하중(P_cr)에 도달하면 갑자기 큰 횡방향 변위 v가 발생하며 불안정해지는 현상.

💥좌굴은 재료 강도와 관계없이 기하학적 불안정성으로 발생한다. 항복응력에 도달하기 전에 일어날 수 있다.

P < P_cr (안정 상태)

작은 섭동(흔들림)이 가해져도 스프링이 복원 → 원위치로 돌아옴

\[ \Sigma M_A < 0 \rightarrow \text{복원모멘트} > \text{전도모멘트} \]

P > P_cr (불안정, 좌굴)

섭동이 가해지면 더 큰 변위로 발산 → 좌굴 발생

\[ \Sigma M_A > 0 \rightarrow \text{전도모멘트} > \text{복원모멘트} \]

임계하중 유도 — 스프링 모델로 이해하기

'기둥 AB + 수직방향 스프링' 모델에서 기둥이 θ만큼 회전했을 때 복원 여부를 판단:

\[ \Sigma M_A = P(l\theta) - F \cdot l = P(l\theta) - \beta(l\theta)l = l\theta(P - \beta l) \]
조건ΣM_A 부호현상
\(P > \beta l\)\(\Sigma M_A > 0\)불안정(좌굴) — 전도모멘트가 복원모멘트를 초과
\(P < \beta l\)\(\Sigma M_A < 0\)안정(복원) — 복원모멘트가 전도모멘트를 초과
\(P = \beta l\)\(\Sigma M_A = 0\)임계하중 P_cr — 중립 안정
임계하중
\[ P_{cr} = \beta l \]
✓핵심 원리: β는 스프링의 복원력(단위 변위당 힘). P_cr을 초과하는 하중이 가해지면 스프링(구조 복원력)이 이를 버티지 못하고 좌굴 발생.
④

오일러 좌굴하중 (Euler Buckling Load) 참고

오일러(Euler)가 1757년 좌굴 미분방정식으로부터 유도한 탄성좌굴하중:

오일러 좌굴하중 (양단 핀 지지 기준)
\[ P_{cr} = \frac{\pi^2 EI}{l^2} \]
임계 좌굴응력
\[ \sigma_{cr} = \frac{P_{cr}}{A} = \frac{\pi^2 E}{(L/r)^2} \]
ℹ P_cr ∝ E (탄성계수) · I (단면 2차 모멘트) / l² (길이²)
→ 길이가 2배 늘면 좌굴하중은 1/4로 감소. 단면 2차 모멘트를 키우거나, 길이를 줄이거나, 지지 조건을 바꾸면 좌굴 저항 증가.
⚠시험 포인트 정리: ① 세장비가 뭔지 (L/r의 정의) ② 기둥에서 일어나는 현상 (좌굴 = 압축보다 휨이 먼저 발생) ③ P > P_cr → 불안정(좌굴), P < P_cr → 안정(복원)

1. 압력을 받는 용기에서 두께를 결정할 때 고려사항이 아닌 것은? 기출

(부탄가스 용기를 떠올릴 것 — 압력용기 두께 설계식의 구성요소를 묻는 문제)

압력용기 두께 설계식 (교수님 필기)
\[ t = \frac{P \cdot D \cdot S}{2\,\sigma_u \cdot \eta} + C \]

P: 내압  ·  D: 지름  ·  S: 안전계수(Safety factor) — 분자
σu: 극한응력  ·  η: 이음효율(용접효율) — 분모
C: 부식 여유(corrosion allowance) — 보통 +1 mm 추가

✓
각 요소가 두께에 미치는 영향
  • 이음효율 η (분모) — η는 1보다 작은 값(용접부가 모재보다 약함).
    η가 작을수록 분모가 작아져 → t가 커진다 (이음부 강도 저하를 두께로 보정).
  • 안전계수 S (분자) — S > 1. 분자에 곱해지므로
    S가 클수록 → t가 커진다 (더 두껍게 만들어 안전 확보).
  • 부식 여유 C (덧셈) — 부식·마모에 의해 닳는 두께를 미리 추가.
    보통 +1 mm 가산 (내압용기 내용물에 의한 부식 고려).
⚠
시험 포인트 — 안전계수는 분모의 허용응력에 숨어 있는 게 아니라 분자에 직접 S로 들어간다는 점에 주의.
\(\sigma_{allow} = \sigma_u / S\) 형태로 쓰면 S가 분모로 내려가지만, 필기 공식처럼 S를 분자에 명시하면 두께가 커지는 방향이 직관적으로 보임.
→ 두께 결정 고려사항: 이음효율 · 안전계수 · 부식 여유 이 세 가지. 이와 무관한 보기가 정답.

2. 프로펠러에 작용하는 하중이 아닌 것은? 기출

✓
정답 해설 — 회전하는 프로펠러 블레이드에 작용하는 하중:
  • 인장 (원심력) — 회전 시 블레이드가 바깥으로 당겨짐
  • 압축 — 공기 추력 반작용
  • 굽힘 · 비틀림 — 추력/공력에 의한 휨, 피치 변화에 따른 비틀림

→ 인장·압축·굽힘·비틀림은 모두 작용. 이 4가지에 속하지 않는 보기(예: 순수 전단만 / 열응력 등)가 정답이다.

3. 동체에 받는 하중을 스킨(외피)으로 전달하며 비틀림 응력과 좌굴을 방지하는 부재는?

✓
정답 — 벌크헤드 (Bulkhead)
동체 구간마다 둥글게 배치되는 격벽 부재. 동체 단면 형상을 유지하고, 집중하중을 외피로 분산 전달하며 비틀림·좌굴에 저항한다. (세로 부재 longeron/stringer, 원주 부재 frame/bulkhead 중 단면형상 유지·하중 분산 역할이 벌크헤드)

4. 장주(긴 기둥)에서 압축파괴 대신 가로방향(횡방향)으로 휘어 발생하는 현상은?

✓
정답 — 좌굴 (Buckling / 버클링)
세장비가 큰 장주는 재료의 압축강도에 도달하기 전에 기하학적 불안정으로 옆으로 휘어버린다. 오일러 좌굴하중 \(P_{cr}=\pi^2 EI/l^2\). ▶ 10장(기둥) 참고

6. 서로 평행한 두 회전축에 대한 동체의 관성모멘트(=단면 2차 모멘트) 관계를 설명한 정리는?

✓
정답 — 평행축 정리 (Parallel Axis Theorem)
평행축 정리
\[ I = \bar{I} + A d^2 \]
도심축 관성모멘트 \(\bar I\)에 \(Ad^2\)(면적 × 축간거리²)를 더하면 평행한 다른 축에 대한 \(I\)가 된다. ▶ 8장 참고

7. 충격응력은 같은 조건에서 정적하중보다 최소 몇 배 이상 작용하는가?

✓
정답 — 최소 2배
충격계수
\[ \delta = \delta_{st}\left(1+\sqrt{1+\dfrac{2h}{\delta_{st}}}\right) \]
낙하높이 \(h=0\)(가만히 얹기만 해도)이어도 충격계수 \(=1+\sqrt{1}=2\). 즉 충격하중은 항상 정적하중의 2배 이상으로 작용한다. ▶ 6장 참고

8. 단면 1차 모멘트의 목적은 무엇을 구하기 위한 것인가?

✓
정답 — 도심 (Centroid)
단면 1차 모멘트 \(Q=\int y\,dA = A\bar y\)이므로 \(\bar y = Q/A\). 즉 1차 모멘트를 면적으로 나누면 도심 위치가 나온다. (도심축에서는 \(Q=0\)) ▶ 7장 참고

9. y축에 대한 단면 2차 모멘트 식은?

✓
정답
y축에 대한 단면 2차 모멘트
\[ I_y = \int x^2\, dA \]
해당 축에서 수직거리의 제곱 × 미소면적을 적분한 값. (x축이면 \(I_x=\int y^2 dA\)). 직사각형(폭 b, 높이 h)의 도심 x축 기준은 \(I_x=bh^3/12\). ▶ 8장 참고

10. 원통형 압력용기에서 원주방향으로 작용하는 응력은?

✓
정답 — 후프응력 (Hoop Stress / 원주응력)
후프응력 vs 축응력
\[ \sigma_\theta = \dfrac{pd}{2t}, \qquad \sigma_x = \dfrac{pd}{4t} \]
후프응력 \(\sigma_\theta\)는 축응력 \(\sigma_x\)의 2배 → 원통은 원주방향이 더 위험. ▶ 2장 참고

11. 등속직선운동에는 없고 등속원운동에는 있는 힘은?

✗ 가속도 (오답 보기)

등속원운동에 구심가속도는 존재하지만, 문제는 "힘"을 묻고 있다. 가속도는 힘이 아니다.

✓ 구심력 (정답)

등속원운동은 속력은 일정해도 방향이 계속 바뀌므로 중심방향 구심력이 필요. 직선운동엔 없다.

주관식

주관식 (2문항) · 계산 문제 없음

1. 물체가 원운동할 때 구심력에 대해 설명하라. (발생되는 과정을 설명) — 키워드: 합력, 벡터, 힘이 발생하는 원리

✎
모범답안 —
  • 속도는 벡터량이다. 등속원운동은 속력(크기)은 일정하지만 매 순간 방향이 변한다.
  • 속도 벡터의 방향이 변한다는 것은 속도 변화량(Δv)이 존재한다는 뜻 → 따라서 가속도가 존재한다.
  • 미소시간 동안의 속도 벡터를 그려 빼면(\(\vec v_2-\vec v_1\)), 그 합력(변화 벡터)의 방향은 항상 원의 중심을 향한다.
  • 뉴턴 2법칙 \(F=ma\)에 의해, 이 중심방향 가속도를 만들기 위해 중심을 향하는 힘 = 구심력이 필요하다.
  • 크기: \( F = ma = \dfrac{mv^2}{r} = mr\omega^2 \). 방향: 항상 원의 중심(안쪽).

정리: 방향이 바뀌는 운동 → 속도 변화(벡터) → 가속도 발생 → 그 합력이 중심을 향함 → 이것이 구심력.

✎
핵심 — 두 운동 모두 속력은 일정하다는 공통점이 있지만, 등속원운동은 속도의 "방향"이 끊임없이 변한다. 따라서 등속원운동에만 가속도(구심가속도)와 알짜힘(구심력)이 존재한다.
★ 최종

시험 전 최종 체크리스트

핵심 원리 요약 + 자주 하는 실수 정리

핵심

꼭 알아야 할 원리들

  1. 열응력 σ = Eα∆T — 응력은 길이와 무관. 변형량 δ = Lα∆T는 길이에 비례. 이 차이 구분.
  2. 압력용기 후프응력 > 축응력 — 후프 = pd/(2t), 축 = pd/(4t) = 후프/2. 원통은 원주방향이 더 위험.
  3. 구심가속도 a = v²/r = rω² — 이등변삼각형 닮음에서 유도. 속력 일정하지만 방향 변화 → 가속도 존재.
  4. 탄성에너지 U = P²L/(2AE) = σ²V/(2E) — P-δ 그래프 아래 삼각형 면적. 단위체적당 u = σ²/(2E).
  5. 경사단면 τ 최대 = 45°에서 σ_x/2 — τ = ½σ_x·sin2θ. 45°에서 sin90° = 1로 최대.
  6. 충격응력 = σ_st × (1 + √(1+2h/δ_st)) — h=0이어도 충격계수 = 2. 항상 정적보다 크다.
  7. 도심 x̄ = ∑A_i·x̄_i / ∑A_i — 복합 도형은 분할 후 가중평균. 구멍은 음수 면적. 도심축에서 Q=0.
  8. 평행축 정리 I = ĪI + Ad² — 축 이동 시 Ad²만큼 추가. I형강은 가장 먼 부분에 면적을 배치해 I 값 극대화.
  9. 비틀림 τ = Tr/I_p, φ = Tl/(GI_p) — τ는 반지름에 비례, 바깥쪽 최대. 극관성모멘트 클수록 응력 감소.
  10. 보 SFD/BMD: dV/dx = −w, dM/dx = V — V=0인 점에서 M이 최대. 집중하중→SFD 수평선·BMD 직선, 균일분포→SFD 직선·BMD 포물선.
  11. 기둥 세장비 λ = L/r — 세장비 클수록 좌굴 저항 작아짐. r = √(I/A). 단주(L/r<50)→압축 파괴, 장주(≥100)→좌굴 파괴.
  12. 기둥 좌굴: P > P_cr → 불안정, P < P_cr → 복원 — 좌굴은 재료 강도 이전에 기하학적 불안정으로 발생. 오일러 P_cr = π²EI/l².
⚠

자주 하는 실수

  • 열응력 공식에 L을 넣으려는 경우 → σ = Eα∆T에 L 없다
  • 후프응력/축응력 어느게 큰지 헷갈리는 경우 → 후프가 2배 크다
  • 단면 1차 모멘트 Q 단위를 mm²로 쓰는 경우 → mm³이다 (면적×거리)
  • 복합도형 도심 계산 시 구멍을 더하는 경우 → 빼야 한다 (음수 면적)
